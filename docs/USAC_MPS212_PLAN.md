# USAC: MPEG Surround 212 (MPS212, stereoConfigIndex 1..3), plan and findings

Status (2026-11-22): **stereoConfigIndex 1 and 2, both with phase coding (M4d) and 2 with residual bands (M4a), with temporal shaping STP, GES and TSD WORK** (M1, M2, M3, M4a, M4d done; residual bands at eSBR 2:1): parameter decoder (`sauti_usac_mps.{c,h}`), signal path (`sauti_usac_mps_dec.{c,h}`), tables (`sauti_usac_mps_tables.{c,h}` from `tools/gen_usac_mps_tables.py`), integration in `element()` of `sauti_usac.c`.  What is NOT done: stereoConfigIndex 3 (pseudo-LR; eSBR after the upmix), phase coding (IPD / OPD), temporal shaping (STP, GES, TSD), eSBR 8:3 with MPS, LPD cores in an MPS element, USAC without eSBR + MPS (the reference does not support it either); such elements / frames are refused as unsupported (-1).

**Verification.** (1) Parameters: the dequantised CLD / ICC, parameter slots and smoothing data of every frame of six libxaac streams (three rates, 24 and 64 kbit/s, 63 - 94 frames each, the full CLD range -150 .. +150 dB and all ICC values) are identical to the reference's (`ixheaacd_mps_apply` after `ixheaacd_mps_frame_decode`, dumped by an instrumented copy: env `MPS_PARAM`). (2) Signal path: the QMF grids that leave the upmix (hybrid analysis, decorrelator with energy adjustment, interpolated gains, hybrid synthesis) agree with the reference's to **1e-7 .. 8e-7** (float noise) in every frame but the first of the four streams (the reference's first frame runs through a start-up path, `pre_mix_req`, that ramps its pre-matrix in; this decoder does not reproduce it: the first frame is in the pre-roll). (3) PCM against `xaacdec`: fixtures `usac_z1..z3` (stereoConfigIndex 2, 48 / 44.1 / 32 kHz, 24 and 64 kbit/s) **75.9 - 76.2 dB**; also 73.7 - 80 dB on four more streams made while developing.

**Finding that is not in the clause text I have.** The reference feeds the upmix with QMF bands 0..2 six slots (4:1: twelve) AHEAD of the other bands: the hybrid analysis delays the three lowest QMF bands by six slots (13 tap filters) and does not delay the rest, so the input is pre-aligned.  The eSBR chain of this library returns both groups aligned; `SautiAacSbrChannel.mps_lf_ahead` makes `sauti_aac_sbr_channel_frame` take bands 0..2 of the grid from `X_low[i + 2 + 6R]` (inside the frame's own 8 + 32 slots, no look-ahead needed).  Without it the decoded stereo image is smeared (PCM 0 dB against the reference).

**Differences from the reference.** (a) Interpolation of the parameter indices (bsXxxDataMode 2): the reference returns an error when the interpolation target exists (`if (i2 < num_parameter_sets) { if (ec_flag == 0) return IA_FATAL_ERROR; }`, apparently inverted); here it follows the clause: interpolate between the previous coded set and the next one, a missing target is an error.  Not verifiable: the encoder of libxaac never writes mode 2.  (b) Left shifts of negative numbers in the indices are written as multiplications (the reference relies on arithmetic shifts).  (c) PCM escape in 2-D CLD pairs: the reference's escape buffer for CLD is declared `[MAXBANDS][2]` but used as two flat arrays (they overlap when three or more escapes occur in one set); here two separate buffers.

**Not verified because the encoder never writes it:** several parameter sets and framing (`bsHighRateMode`), data modes 1 / 2 with changing quantisers, IPD / OPD, smoothing modes 2 / 3, PCM escapes, time pairs in every combination (the hand-made frames of `tests/test_usac_mps.c` cover PCM sets, strides, default / keep, framing and refusals).

**Memory.** The state of a decoder instance grew from 774 KiB to about 1.1 MiB: `SautiUsacMpsDec` (16.4 KiB per element: with the residual analysis state) and the low band buffers of the 4:1 transposer (`hbe_low` sized for 64 slots, 32 KiB per channel).  Worth a diet (the second `hbe_low` is used only to replay the transposer after a header change).

## Oracle and test streams

* libxaac's encoder makes MPS212 streams: `xaacenc -aot:42 -usac:1|2 -esbr:1 -ccfl_idx:3 -mps:1 -tree_cfg:0 -br:32000 in.wav` (stereo input at the OUTPUT rate; `-tree_cfg:0` = '212'; without it the encoder prints "Invalid tree config" and falls back). The default stream has `stereoConfigIndex 2` (a residual channel is coded but `bsResidualBands = 0`: no residual is used), `bsFreqRes` index 1 (28 parameter bands), `bsFixedGainDMX` 2, no temporal shaping (`bsTempShapeConfig 0`), `bsDecorrConfig 0`, no phase coding, `bsHighRateMode 0` (one parameter set per frame).  Helper scripts of the session: `/tmp/claude-1000/mps/` (`dec.sh`, `cfg.c`), not in the repository.
* The decoder side of libxaac is the general MPEG Surround decoder (`decoder/ixheaacd_mps_*.c`, 34 700 lines with 8 300 lines of tables, of which 212 uses a fraction): `ixheaacd_mps_frame_parsing` (Mps212Data), `ixheaacd_mps_frame_decode` (parameters -> matrices), `ixheaacd_mps_apply` (hybrid analysis, decorrelator, matrices, hybrid synthesis, temporal processing), `ixheaacd_mps_calc_m1m2_*`, `ixheaacd_mps_smoothing`, `ixheaacd_mps_hybrid_filt`, `ixheaacd_mps_decor`, `ixheaacd_mps_res_*` + `ixheaacd_mps_mdct_2_qmf` (residual), `ixheaacd_mps_temp_process` / `ixheaacd_mps_reshape_bb_env` (STP / GES temporal shaping), Huffman tables in `ixheaacd_mps_rom.c` (node arrays, lines 39 - 7860; the CPC tables at 7863 are for 5-1-5 trees and are not needed).

## Where it sits in the access unit and in the signal path (for stereoConfigIndex 1 and 2; index 3 applies eSBR AFTER the upmix, `mps_sbr_flag` in the reference)

* Order in a channel pair element (`ixheaacd_process.c`): core data of `nrCoreCoderChannels` (1 for stereoConfigIndex 1, 2 for 2 and 3: the second is the residual) -> optional pseudo-LR M/S (`mps_pseudo_lr`, index 3) -> SBR data -> **Mps212Data** (`ixheaacd_mps_frame_parsing`).
* The upmix works in the **QMF domain AFTER eSBR**: the mono downmix goes through the core, eSBR makes its 64-band QMF grid (32 slots at 2:1), the MPS hybrid analysis (the three lowest QMF bands are split into 8 / 2 / 2 sub-bands, 71 hybrid bands for 64 QMF bands) runs on that grid, the matrices and decorrelator make two hybrid signals, hybrid synthesis gives two QMF grids and each gets its own synthesis filter bank. This matches the structure of this library (`sauti_aac_sbr_channel_frame` returns the grid, `sauti_aac_sbr_channel_synthesize` makes PCM), so MPS212 can be a module between them: `grid_mono -> grid_left, grid_right`.
* Stereo configuration 3 sets `mps_sbr_flag` in libxaac (SBR handled differently); 1 and 2 do not.

## Mps212Data (frame syntax, verified by reading `ixheaacd_mps_frame_parsing`)

`bsHighRateMode`: `bsFramingType` (1) + `numParamSets - 1` (3), else one parameter set. With `bsFramingType`: `bsParamSlot[i]` (5 bits at 32 slots, 6 at 64), strictly increasing; without: slots `((slots * (i + 1) + sets - 1) / sets) - 1`. `bsIndependencyFlag` (only when the AU's usacIndependencyFlag is 0). EcData for CLD, ICC, then (with `bsPhaseCoding`) `bsPhaseMode` (1), `bsOpdSmoothingMode` (1) and EcData for IPD; with `bsHighRateMode`: per parameter set `bsSmoothMode` (2), `bsSmoothTime` (2, mode >= 2), `bsFreqResStrideSmg` (2) and `bsSmgData` per group (mode 3); temporal shaping: config 3 -> `bsTsdEnable` (1) + TSD data (transient slots as a combinatorial codeword), 1 -> `bsTempShapeEnable` + `bsTempShapeEnableChannelSTP[2]`, 2 -> GES flags + Huffman coded envelope per channel.
EcData (`ixheaacd_mps_ecdata_decoding`): `bsXxxDataMode[set]` (2): 0 default, 1 keep, 2 interpolate, 3 new data; new data per pair of sets: `bsDataPair` (1), `bsQuantCoarse` (1), `bsFreqResStride` (2), coarse / fine conversion of the previous indices, stride map, then Huffman (`ixheaacd_mps_ecdatapairdec`: pilot, 1-D / 2-D codes, time / frequency pairs, lav index, symmetry restore, PCM escape with grouped codewords).

## Stages

* M0 (done): plan, oracle.
* M1 (done): Mps212Data + EcData parser, Huffman node tables through a generator + register entry; checked against an instrumented libxaac.
* M2 (done): dequantisation, band mapping, interpolation, smoothing data; the upmix gains (rotation and prediction forms) are in the signal path.
* M3 (done): hybrid analysis / synthesis, decorrelator, matrix application, QMF grids, PCM of libxaac's `-mps:1` streams (`stereoConfigIndex 2` with no residual bands).
* M4a (done 2026-11-22): residual bands.  The libxaac ENCODER cannot produce any of the M4 tools (`xaacenc -h` has only `-mps` and `-tree_cfg`; its streams always carry a silent second core channel with `bsResidualBands = 0`), so the test streams come from `tools/sauti_usac_gen.c` (`--mps 2 --mps-res B --mps-decorr D`, Mps212Data as PCM sets) and from a PATCHED encoder stream.  In libxaac the residual of the USAC 212 element is the SECOND core channel put through the same 32 band QMF analysis as the downmix (NOT through `ixheaacd_mdct2qmf_process`, which belongs to the general MPS path), analysed by its own hybrid filter (39 hybrid bands) and used in the parameter bands below `bsResidualBands` instead of the decorrelator output (upmix gains: direct (w - rw, w + rw), residual (w, -w) below the limit, decorrelator (beta, -beta) above it); its QMF bands 0..2 arrive six slots ahead of bands 3..31 (`sauti_usac_mps212_residual_grid`).  `bsResidualBands` is a 5-bit field at bit 80 of the AudioSpecificConfig of the encoder's default 48 kHz stream; to patch such a stream the SAME bits must be changed in the copy of the configuration inside the AUDIOPREROLL payload of the first access unit (bit 35 of it; found by a bit search), because libxaac's decoder takes the configuration from there (a patch of the AudioSpecificConfig alone changes nothing: the first attempt of this stage concluded wrongly that the residual path is a no-op).  Results and verification: docs AAC_FAMILY_ASM.md SBR-117.  An old bug of M3 was found on the way (decorrelator configuration 2: unsigned underflow in `split - 1u`).
* M4d-cfg1 (done 2026-11-22): phase coding (IPD / OPD) of stereoConfigIndex 1, see AAC_FAMILY_ASM.md SBR-118 (fixed-point OPD smoothing as the reference, complex mix with the sign flip in hybrid bands 0 and 1; generator `--mps 1 --mps-phase 1`).
* M4d-cfg2 (done 2026-11-22): phase coding with the prediction upmix (imaginary part of the matrix on the direct signal, anti-phase special case); SBR-118.
* M4c-STP (done 2026-11-22): temporal shaping STP (bsTempShapeConfig 1), SBR-119; second oracle FDK (`scripts/test_usac_mps_vs_fdk.sh`).
* M4c-GES (done 2026-11-22): guided envelope shaping (bsTempShapeConfig 2), SBR-120; agrees with libxaac, differs from FDK by about 25 % in the amplitude of its effect (open).
* M4c-TSD (done 2026-11-22): transient steering decorrelator (bsTempShapeConfig 3), SBR-121; libxaac 6e-7, FDK effect correlation 0.9998.
* M4b-rest: pseudo-LR (index 3, eSBR after upmix); residual at eSBR 4:1 / 8:3.  Original M4 list: residual coding (`bsResidualBands > 0`: the second core channel as MDCT -> QMF residual), pseudo-LR (index 3), temporal shaping (STP, GES, TSD), phase coding (IPD / OPD).
* M5: fixtures, fingerprints, generator (`--mps`), mutations, fuzzing, docs.
