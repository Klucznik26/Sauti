# USAC eSBR: harmonic transposer (HBE), plan and findings

Status (2026-11-22): DONE for eSBR 2:1 and 4:1 (and written for 8:3, unverified): syntax, transposer, HF generation, limiter borders, one frame latency, reset replay; see docs/AAC_FAMILY_ASM.md SBR-115 for the result and the verification (transposer 2.4e-7 against libxaac, PCM 72-76 dB on libxaac streams, 50-60 dB on generator streams).  Open: 8:3 check, patches 5 / 6 of 4:1 in a stream, the DFT variant.

## Reference and provenance

* Independent oracle: libxaac (Apache 2.0, built outside this repository, `~/Sauti-tools/libxaac`, commit 2fbadd5). Its **encoder emits real HBE streams** (`-harmonic_sbr:1`), so no bit flipping of the ASC is needed. `-esbr_hq:1` selects the DFT based transposer (a different algorithm, `ixheaacd_hbe_dft_trans.c`), not planned.
* The ISO text is not available. The algorithm was read from `decoder/ixheaacd_hbe_trans.c`, `ixheaacd_esbr_polyphase.c`, `ixheaacd_sbr_dec.c`, `ixheaacd_sbrdec_lpfuncs.c` (ixheaacd_generate_hf), `ixheaacd_esbr_envcal.c` (limiter bands) and is written again for Sauti (own data layout, double precision, no pointer arithmetic over the 128-column buffers). Tables: data only, through `tools/gen_usac_hbe_tables.py`, one register entry per table in BIBLIOTEKA_PLAN.md, Apache 2.0 NOTICE (same rules as the PVC tables).
* Test streams: `/tmp/claude-1000/hbe/mk.sh <name> <ccfl_idx> -harmonic_sbr:1` (scratch, not in the repository). The encoder writes frames with `sbrPatchingMode = 0` and `sbrPitchInBins = 24` (and the first frame with patching mode 1), so the pitch-dependent "cross product" branch (`p = pitch_in_bins / 12 >= 1`) is the common one; the plain products (`p < 1`) need streams of the own generator.
* Instrumented libxaac copy (`/tmp/claude-1000/xaacdbg/src`, env `HBE_DUMP` / `HBE_DUMP2`): per frame the 32 new low-band QMF rows going into the transposer, the 32 rows it produced (`ph_vocod`), and the carrier after `ixheaacd_generate_hf` (40 rows); header = frame marker, no_bins, start_band, end_band, k_start, synth_size, max_stretch, pitch_in_bins, patching_mode, x_over_qmf[6], delay.

## Map of the reference algorithm (2:1; 8:3 identical with the 24 band QMF; 4:1 adds `hbe_repl_spec`)

1. `hbe_data_reinit` (on every header change): `start_band = low[0]`, `end_band = low[n_low]`, `synth_size = 4 * ((start_band + 4) / 8 + 1)` (4..20), `k_start = start_subband2kL[start_band]` (limited to 16 - synth_size for 4:1, 24 - synth_size for a 768 core), x_over_qmf[patch] = highest low-resolution band edge <= patch * start_band (if the distance is > 3 the high-resolution table is used instead), `max_stretch` = number of patches that fit (<= 4; 6 patches for 4:1).
2. Per frame of `no_bins` QMF slots: (a) real synthesis of the `synth_size` low-band QMF bands starting at `k_start` (modulation with `cos_table_trans_qmf`, then a `synth_size` band cosine-modulated filter bank with a sub-sampled prototype of 10 * synth_size taps) = `synth_size` time samples per slot; (b) complex analysis with `2 * synth_size` bands (window 10 * 2 * synth_size) = one complex column per two slots, written to `qmf_in_buf[12 + idx][2*k_start ...]` (12 columns of context kept); (c) products: T = 2, 3, 4 (`post_anal_prod2/3/4` for p < 1, `post_anal_xprod2/3/4` for the pitch case), each normalising the input with |x|^-(T-1)/T style factors (`norm_qmf_in_buf`, cube roots), interpolating half-band neighbours with `sel_case` / `interp_coeff`, accumulating into `qmf_out_buf` (64 rows, the second 32 rows wait for the next frame); (d) rotation by `phase_vocoder_cos/sin[band]` into `ph_vocod` rows.
3. `generate_hf` with HBE (`sbr_patching_mode == 0`): the classic patching is skipped; for every band k2 in [sub_band_start, usb) the second-order covariance LPC of the `ph_vocod` signal in that band (over co_var_len = 38 slots) is computed and applied with the chirp factor of the band's noise band, `alpha` reset when |alpha|^2 >= 16 (the same rule as the classic LPC).
4. Limiter bands (`createlimiterbands`): the patch borders come from `x_over_qmf - sub_band_start` instead of the patch table when `sbr_patching_mode == 0`; the limiter tables are rebuilt when the patching mode changes.
5. Latency: the transposer output of a frame belongs to the PREVIOUS frame's low band (the output half of `qmf_out_buf` lags by 32 slots; the codec QMF buffer carries `ESBR_HBE_DELAY_OFFSET = 32` extra slots). The transposer runs in EVERY frame of a harmonic stream (also in frames with patching mode 1) so that its state stays continuous. Measured: a click in the input comes out at the same position (+148 samples) with and without `-harmonic_sbr`, i.e. libxaac's decoder output is NOT one frame later; how the 32 slots are absorbed (encoder timeline) is still to be determined by experiment.
