# Amiga audio

Candidates: 8SVX, 16SV, MAUD, SoundTracker MOD, MED, OKT, AHX, HivelyTracker and other well-documented replay formats. Share IFF parsing with `../../containers/`. Tracker modules and synthetic music are not ordinary PCM files and should use a separate replay interface.

`maktabasauti_svx.c` decodes IFF 8SVX. `maktabasauti_16sv.c` decodes IFF 16SV: the same chunks, with signed 16-bit big-endian samples in `BODY`, left block then right. Playback is uncompressed PCM. `sCompression` 1 and 2 are refused: SoundFX names Fibonacci-delta 8:3 and exponential-delta 16:5 without a delta table or a bit layout. `CHAN` outside 2, 4 and 6 is refused, so a four-channel file is not guessed. When `ctOctave` is greater than 1, 8SVX and 16SV play the lowest octave once. The highest octave is `oneShotHiSamples` plus `repeatHiSamples` and comes first, and each lower octave is twice as long (EA, 7 February 1985). `ctOctave` 0 or 1 plays the whole `BODY`. A seekable 8SVX `SEQN` plays that list once: each entry is a longword-aligned start and an exclusive end, in bytes of one channel, and stereo uses the same offset on both sides. `ctOctave` above 1 together with `SEQN` is refused. 16SV does not apply `SEQN`. `FADE` (Peter Norman) is one big-endian loop number on a `SEQN`. Loop 1 is the first pair. When that loop is reached, sample `i` of the remaining sequences, including the current one, is multiplied by `(R - i) / R`, so the first fade sample stays full and the volume reaches zero as the last sample ends. `VHDR.volume` is not applied, and the ramp is not quantized to 64 hardware steps. A `FADE` without `SEQN`, the number 0, or a number past the last pair does not scale. A size other than 4, or a second `FADE`, is refused. 16SV does not apply `FADE`. `PAN` is not applied: its note defines Unity as 10000, while 8SVX defines Unity as `0x10000`. `maktabasauti_maud.c` decodes IFF MAUD from Richard Koerber's August 1997 description: a 32-byte `MHDR`, rate = `mhdr_RateSource / mhdr_RateDevide` (a remainder is refused), and length from the `MDAT` chunk. Uncompressed samples are MSB-first with no byte padding; exactly 8 bits are unsigned and every other width from 1 to 32 is signed two's complement, interleaved. A-law and mu-law use the public G.711 expansion. `MCI_MONO`, `MCI_STEREO`, `MCI_MULTIMONO` and `MCI_MULTISTEREO` are played, at most 32 channels. `MCI_MULTICHANNEL` (`MINF`), Fibonacci-delta, ADPCM 2 through 5 and DAT longplay are refused. `maktabasauti_samp.c` decodes IFF SAMP when `NumOfChans` is 0: each wave is linear PCM played once at its `Rate`, in file order, one channel. Format 8 is a signed byte, formats 9 through 16 are a left-justified signed big-endian word, and formats 17 through 28 are a left-justified signed big-endian long. A `PlayMap`, a nonzero `VelStart`, and the note-off loop are refused. A later wave keeps its own `Rate`: the read stops on that boundary, the next read returns `E_FORMAT_CHANGED` with no frames, and `get_info` then reports the new rate. A seek onto a wave with a different `Rate` does the same before the first sample. Samples are not resampled. `maktabasauti_mod.c` is an original replay for the MOD family: 31-instrument signatures (`M.K.`, `M&K!`, `FLT4`, `EXO4` and `N.T.` up to 64 patterns; `M!K!`, `PATT`, `NSMS` and `LARD` up to 256; `xCHN` 1..9; `xxCH` and `xxCN` 10..99; `TDZ1`–`TDZ9`; `CD61`; flat `CD81`, `OCTA` and `OKTA`; `FA04`, `FA06` and `FA08`), StarTrekker `FLT8`, `EXO8` and `EX08` as a pair of 4-channel patterns, and the signature-less 15-instrument header. That header is claimed only when the song length at offset 470 is 1..128, every sample volume is 0..64, and every order byte is below 64. A length byte alone is not a module. `FLT6` is rejected: StarTrekker's author described `FLT4` and `FLT8` only, and 6 channels are `6CHN`. The replay mixes Paula periods from the published 16 by 60 table. Nonzero finetune retunes the written period onto that column before the note plays. Finetune 0 keeps the written period. The default clock is PAL `3546895`. Host option `mod.clock` `ntsc` selects `3579545`. The file does not store the clock. Stereo pan repeats the Amiga pairs, left right right left. `Cxx`, `Fxx`, arpeggio, portamento, vibrato, tremolo, volume slide, sample offset, panning, `Bxx`, `Dxx` and `Exx` change playback. ProTracker clears a tone-portamento target when the period reaches it. A note played before the slide arrives leaves that target, so a later `3xx` without a note still slides toward it. After the slide has arrived, `3xx` without a note does not move the period. Soundtracker 2.5 and 2.6 keep the older rule and replace the target when a note is triggered. `E00` enables a 3275 Hz LED low-pass and any other `E0x` turns it off. Host option `mod.model` `a500` adds a fixed 4900 Hz one-pole; the default leaves that filter off. `EFx` adds its per-tick increment and, once the counter reaches 128, inverts one byte of the sample loop through a private mask. `EF0` clears that effect. A sample with no loop is unchanged, and the mapped file is not written. On read, the default clears the first two bytes of every sample. The file does not store the tracker version. Host option `mod.tracker` `pt10` or `protracker10` clears four bytes and plays the old Funk Repeat instead of the invert-loop XOR. The walk limit is twice the length in words, modulo 65536. A sample of 32768 words or more stays on the real loop start or stops short of the sample end. Missing, empty, `pt`, `protracker`, and `pt11` stay on ProTracker 1.1. A jump back onto a row already played ends the song. `E6x` repeats a section a finite number of times and does not trip that end. ProTracker keeps the E6x loop row and counter when the order changes, so a later pattern can jump forward to the stored row. `9xx` adds the offset to the played index and again to the start of the next note. An instrument number clears that start. A loop that begins at byte 0 plays the whole sample once, then the loop. `F00` holds the row: a looping channel has unknown length, and a one-shot ends when it goes silent. On a 15-instrument module every nonzero `Fxx` is speed. `Bxx` past the order list jumps to position 0, and the already-played check can still end the song. An invalid restart byte, including `0x78` and `0x7F`, tries order 0 and ends when that row has already started. A sample number without a note changes the volume immediately. The sounding sample continues until its current run ends, then the latched loop plays, or the channel stays silent when that sample does not loop. A loop latched after the previous sample has already stopped starts at the loop. A later note starts the latched sample from the beginning. Waveform 3 is the square wave, the same shape as waveform 2. ProTracker documentation calls that waveform random; the tracker plays a square, and this replay does not add a random generator. Tremolo ramp uses the ProTracker half-position bug. Tag `name.N` reads the instrument name. Host option `mod.tracker` `ust` or `ultimate` plays Ultimate Soundtracker group 1: effect 1 is arpeggio, effect 2 with only one nonzero nibble is portamento up or down, and every other effect is ignored. A loop start is a byte offset and only the loop plays. The finetune byte is ignored for playback. Sample bytes are read as stored. On a 15-instrument file, byte 471 is the initial tempo, and 120 becomes BPM 121. A sample longer than 9998 bytes is rejected. Host option `mod.tracker` `st2` or `soundtracker2` plays SoundTracker II through VI: ProTracker arpeggio and portamento, `Cxx` volume, `Dxy` volume slide, `Exy` auto-slide until a parameter of 00, and `Fxx` speed from the low nibble only. `st9` or `master` plays SoundTracker IX and Master Soundtracker: the same arpeggio, portamento, volume and low-nibble speed, `E0x` filter, `Bxx` position jump, and a pattern break that always starts the next pattern. Both share the 15-instrument tempo byte, the byte loop start and the ignored finetune with `ust`. Samples stay within 9998 bytes for `st2` and 32768 bytes for `st9`. `tjc` or `jungle` plays The Jungle Command SoundTracker II: effects 3 through B modulate the next channel and the modulating channel is silent. Arpeggio takes five passes, high nibble, low nibble, the note, high, low, and portamento runs on every pass. `Dxy` applies both nibbles. The default speed is 5. Byte 471 is not a tempo. `st23` or `st24` plays DOC Soundtracker 2.3 and 2.4: the Master Soundtracker commands plus `Axy`, a byte loop, samples up to 32768 bytes, and no tempo byte. Arpeggio uses the triggered note and stops adding after six ticks. `st25` plays Soundtracker 2.5: NoiseTracker commands, a word loop played from the start, samples up to 65536 bytes, and `Fxx` speed modulo 32. Vibrato keeps the ProTracker depth. Soundtracker 2.6 and Ice Tracker are the magic at offset 1464: `MTN` and a zero byte, or `IT10`. The format note types `MNT`; the published dump is `MTN`. Byte 951 counts stored tracks and is not a restart. Each position names four tracks, and a track is one channel of 64 rows. The file selects this replay, so there is no `mod.tracker` word. Finetune is not played, the sample prefix is not cleared, and a word loop plays from the start. The note names the commands without a parameter protocol: arpeggio, portamento, vibrato, volume slide and the pattern break use the ProTracker handlers, `Fxx` is speed modulo 32 and zero does not hold, and `E` is only the LED filter (zero on, any other parameter off). Effects 5, 6, 7, 8 and 9 are ignored. No sample-size cap is added. These words do not change an `M.K.` file opened without them. Any other `mod.tracker` value is rejected. Mod's Grave is a separate codec. It is selected when the name ends in `.wow` and the magic is `M.K.`, then it plays flat 8 channels with the same effects as ProTracker. A file opened without that extension stays 4-channel `M.K.`, including one whose size, restart and sample volume match an 8-channel module. The channel count for `xxCH` and `xxCN` runs through 99. The decoder is registered in the player. The integer Paula voice sum is NASM and matches the C formula on the existing tests. The LED filter and the optional A500 one-pole stay in C.

No other Amiga format is claimed.
