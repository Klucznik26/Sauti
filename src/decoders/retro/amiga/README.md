# Amiga audio

Candidates: 8SVX, 16SV, MAUD, SoundTracker MOD, MED, OKT, AHX, HivelyTracker and other well-documented replay formats. Share IFF parsing with `../../containers/`. Tracker modules and synthetic music are not ordinary PCM files and should use a separate replay interface.

`maktabasauti_svx.c` decodes IFF 8SVX. `maktabasauti_mod.c` is an original replay for the MOD family: 31-instrument signatures (`M.K.`, `M&K!`, `FLT4`, `EXO4` and `N.T.` up to 64 patterns; `M!K!`, `PATT`, `NSMS` and `LARD` up to 256; `xCHN` 1..9; `xxCH` and `xxCN` 10..32; `TDZ1`–`TDZ9`; `CD61`; flat `CD81`, `OCTA` and `OKTA`; `FA04`, `FA06` and `FA08`), StarTrekker `FLT8`, `EXO8` and `EX08` as a pair of 4-channel patterns, and the signature-less 15-instrument header. That header is claimed only when the song length at offset 470 is 1..128, every sample volume is 0..64, and every order byte is below 64. A length byte alone is not a module. `FLT6` is rejected. The replay mixes Paula periods from the published 16 by 60 table. Nonzero finetune retunes the written period onto that column before the note plays. Finetune 0 keeps the written period. The default clock is PAL `3546895`. Host option `mod.clock` `ntsc` selects `3579545`. The file does not store the clock. Stereo pan repeats the Amiga pairs, left right right left. `Cxx`, `Fxx`, arpeggio, portamento, vibrato, tremolo, volume slide, sample offset, panning, `Bxx`, `Dxx` and `Exx` change playback. `E00` enables a 3275 Hz LED low-pass and any other `E0x` turns it off. Host option `mod.model` `a500` adds a fixed 4900 Hz one-pole; the default leaves that filter off. `EFx` adds its per-tick increment and, once the counter reaches 128, inverts one byte of the sample loop through a private mask. `EF0` clears that effect. A sample with no loop is unchanged, and the mapped file is not written. On read, the default clears the first two bytes of every sample. The file does not store the tracker version. Host option `mod.tracker` `pt10` or `protracker10` clears four bytes and plays the old Funk Repeat instead of the invert-loop XOR. Missing, empty, `pt`, `protracker`, and `pt11` stay on ProTracker 1.1. A jump back onto a row already played ends the song. `E6x` repeats a section a finite number of times and does not trip that end. `9xx` adds the offset to the played index and again to the start of the next note. An instrument number clears that start. A loop that begins at byte 0 plays the whole sample once, then the loop. `F00` holds the row: a looping channel has unknown length, and a one-shot ends when it goes silent. On a 15-instrument module every nonzero `Fxx` is speed. `Bxx` past the order list jumps to position 0, and the already-played check can still end the song. An invalid restart byte, including `0x78` and `0x7F`, tries order 0 and ends when that row has already started. A sample number without a note changes the volume immediately. The sounding sample continues until its current run ends, then the latched loop plays, or the channel stays silent when that sample does not loop. A loop latched after the previous sample has already stopped starts at the loop. A later note starts the latched sample from the beginning. Waveform 3 is the square wave, the same shape as waveform 2. ProTracker documentation calls that waveform random; the tracker plays a square, and this replay does not add a random generator. Tremolo ramp uses the ProTracker half-position bug. Tag `name.N` reads the instrument name. Host option `mod.tracker` `ust` or `ultimate` plays Ultimate Soundtracker group 1: effect 1 is arpeggio, effect 2 with only one nonzero nibble is portamento up or down, and every other effect is ignored. A loop start is a byte offset and only the loop plays. The finetune byte is ignored for playback. Sample bytes are read as stored. On a 15-instrument file, byte 471 is the initial tempo, and 120 becomes BPM 121. A sample longer than 9998 bytes is rejected. Host option `mod.tracker` `st2` or `soundtracker2` plays SoundTracker II through VI: ProTracker arpeggio and portamento, `Cxx` volume, `Dxy` volume slide, `Exy` auto-slide until a parameter of 00, and `Fxx` speed from the low nibble only. `st9` or `master` plays SoundTracker IX and Master Soundtracker: the same arpeggio, portamento, volume and low-nibble speed, `E0x` filter, `Bxx` position jump, and a pattern break that always starts the next pattern. Both share the 15-instrument tempo byte, the byte loop start and the ignored finetune with `ust`. Samples stay within 9998 bytes for `st2` and 32768 bytes for `st9`. Any other `mod.tracker` value is rejected. Mod's Grave is not a signature of this family. The channel count stops at 32. The decoder is registered in the player. The integer Paula voice sum is NASM and matches the C formula on the existing tests. The LED filter and the optional A500 one-pole stay in C.

No other Amiga format is claimed.
